# bilisim-odev
1. markdown nedir markdown metinleri kolay şekillendirmeyi sağlyan hafif bir işaretleme dili karmaşık kodlara gerek olmadan başlıklar listeler kalın yazılar oluşturmaya yarar
2. README soyası nedir README dosyası bir projenin ne olduğunu nasıl kullanılcağını anlatır ana tanıtım belgesidir repoya giren birinin proje hakkında hızlı bir şekilde bilgi sahibi olmasını sağlar
3. proje versiyon/sürümleri nedir proje versiyonları yapılan güncellemeleri değişiklikleri takip etmek için kullanılır genelde sürümlerde 1.0.0 şeklinde üçlü bir numara sistemi kullanılır
baştaki sayı: projede çok büyük bir değişiklik yapıldığında arttırılır
ortadaki sayı: projeye yeni bir özellik eklendiğinde arttırılır
sondaki sayı: sadece küçük hataları düzelttiğinde arttırılır
